# 第22步：完整负载实验

本步一次完成：四算法 × 1–8 条业务链的 32 组实验、原始记录、汇总、六幅 PNG 曲线图、HTML 和 Markdown 报告。现有 Java 源码不由本工具修改。

## 在哪里运行
在 Windows PowerShell 中进入原 simulation 目录，然后运行：

~~~powershell
& "..\第22步_负载实验工具包\run-load-study.ps1"
~~~

默认编译一次，运行 32 个独立 Maven/JVM 进程。进度形如 [1/32]。编译或单次运行失败时停止，不自动重试。单个进程超过 180 秒时终止该进程树，保留日志。通常需要数分钟，具体取决于 Maven 和电脑状态。

图表使用 Windows 自带的 .NET Charting；不安装 Python、绘图库或额外 Java 包。运行脚本使用已有 Maven、JDK21 和已安装的 CloudSim 依赖。

## 结果在哪里
运行结束会显示 REPORT 和 SUMMARY 路径。每轮单独建立：
simulation/results/load-study-时间-编号/

- report.html：用浏览器打开，查看全部表格、六幅图及比较条件。
- report.md：可用于整理汇报或小论文的描述性结果材料。
- figures/：六张 1440×900 PNG，图中文字用英文，方便论文或 PPT 引用。
- runs.csv：逐次运行记录，每行包含链数、重复编号及原始指标。
- summary.csv：每个负载和算法一行；普通指标取均值，规划耗时另保存中位数、最小值和最大值。
- time-comparisons.csv：相同就绪服务数和完整链数下，Beam Search 相对各基线的时间差。
- raw/、logs/：单次 CSV 与完整日志。
- manifest.json、source-hashes.csv、snapshot/：配置、Maven/JDK信息、哈希、源码及工具快照。

## 可选参数（首次默认运行即可）
~~~powershell
# 只验证三个负载点
& "..\第22步_负载实验工具包\run-load-study.ps1" -ChainCounts 1,3,6

# 每个组合运行三次，共96次
& "..\第22步_负载实验工具包\run-load-study.ps1" -Repetitions 3

# 项目不在工具包旁边时，显式指定目录
& "..\第22步_负载实验工具包\run-load-study.ps1" -ProjectRoot "D:\路径\simulation"

# 已有完整runs.csv时，仅重新生成图表和报告，不重新跑仿真
& "$env:WINDIR\System32\WindowsPowerShell\v1.0\powershell.exe" -NoProfile -File "..\第22步_负载实验工具包\build-report.ps1" -BatchDir "D:\路径\load-study-时间-编号"
~~~

## 如何解释
先比较完整链与服务就绪数量，再看时间。只接纳较少服务时的短部署时间，不直接等价于更优。CPU/RAM reserved 是资源容量预留，不是实测利用率；高或低都需要结合接纳数量及所选系统版本解释。

固定节点下的合成负载是本阶段的范围。独立 JVM 的计时包含预热等波动；本工具不执行显著性检验，不把重复确定性输入当作独立工作负载。真实 Linux/Windows 容器、VxWorks RTP、API/驱动和安全策略适配仍需后续验证。
